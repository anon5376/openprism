# Scientific PDF design

Start with the manuscript’s main comparison, its evidence type, and any publisher template. Keep the template’s page size, fonts, caption conventions, and reference style when supplied. Read the source for values, qualifiers, labels, citation keys, and figure references before moving them.

For a short results note, put the study setting near the title. Lead with the observation a reader needs to interpret the rest of the page. Give exact comparisons a table and reserve figures for relationships the reader can see more readily than read. An abstract or separate cover earns its space when it serves a distinct purpose.

Set the body at a comfortable print size, with enough leading for subscripts and math. Choose the text width before setting figure and table widths. Align headings, captions, and the main text to a common left edge. Wrap long labels or split a wide table before shrinking type. Keep numbers and units together. Let the caption travel with its figure or table.

For a statistical graphic, consult the scientific-figure-design skill. Make the caption identify the population or simulation, the statistic, the comparator, and the interval type wherever those details affect interpretation.

Use the project’s existing engine, fonts, and packages where possible. Preserve semantic LaTeX labels and references. Compile the deliverable and inspect each rendered page at reading size when tools permit. Check page breaks, cropped marks, minus signs, superscripts, and agreement between prose and figure labels. In an editor session with proposal tools only, leave a specific compile or visual check for the writer.
